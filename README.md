# Complete invitation

Extract the entire ZIP. Keep the assets folder beside index.html.
Open index.html using VS Code Live Server, or upload the entire folder to hosting.

Music uses assets/music/track-1.mp3 and track-2.mp3. Two original synthesized flute-style instrumentals are included. Your personal audio files were not attached, so they are not in this package. To use your recordings, replace these two MP3s with your files using exactly these names.

Browsers may block sound on opening. If the tap hint appears, tap anywhere once. No music button is added. Video plays silently, then the invitation opens; the same music continues through the transition.

If you replace a previously hosted version, refresh without cache or test in a new private window. Upload every file and folder, not only the HTML.
